# Sky Crown Athletic

Standalone HTML 3D athletic game.

## Deploy to Vercel

1. Import `tanuki276/DIEGOgames` in Vercel.
2. Set **Root Directory** to `Sky-Crown-Athletic`.
3. Set **Framework Preset** to **Other**.
4. Leave the Build Command empty (no build step is required).
5. Set **Output Directory** to `.` if Vercel asks for it.
6. Deploy.

The entry point is `index.html`; the game is self-contained and does not require a package install or build command.
